# Earth-flash · 大地图远征

2026-09-14。同步完善 Earth2 的游戏方向，保留原有 Three.js 实时战场与完整可玩系统。

## 内容

- **边境前线 / Frontier320**：3200 × 1800，四处湖泊与多路补给线。
- **双湖走廊 / TwinLakes280**：2800 × 1575，两座大湖之间的岸线推进。
- **高地远征 / Highland360**：3600 × 2025，更多岩丘和侧翼路线。
- 每图 12 处矿区，外围富矿收入更高。道路、湖泊、岩丘、出生点、迷雾和小地图使用同一战区数据。
- 地面寻路绕开水域、岩丘和建筑，舰艇在所属海域活动，飞机可越水；支持远端侦察、建设、生产、研究、技能、占领、采矿运输与维修。
- 敌军扩张资源、保留总部守军并反攻。开局无补充部队的简单直冲会遇到守军；生产和研究后可以完成三张地图的完整任务。

## 使用

顶部战区按钮打开选择菜单；底部小地图可定位，展开为战略地图后可右键给所选部队下令。查看地图时暂停，关闭恢复原状态。部署新战区前自动保存到本地，存储失败会显示错误并保留当前对局。顶部载入按钮可恢复前一对局，经典地图存档继续兼容。

仍使用原固定地址 `http://localhost:5173/`。本轮保留 Sites 配置与 Worker，无发布或提交操作。

## 视觉和验证

战场使用 Earth2 本地草地、土路贴图与已有 GLTF 单位／建筑，补充动态战区树林、湖岸、岩丘、道路、单位路线和行进尘效。HUD 保留青边玻璃浮层、小地图、中央部队操作和建筑牌。

`npm test` 的 60 项测试通过，包括三图完整生产＋研究＋攻坚胜利、反攻失败、36 条据点路线逐步验证、海军生产维修、远端建设、独立地图与迷雾、存档迁移与损坏存档拒绝。原始输出见 `docs/expansion-tests.txt`。`npm run build` 与 `npm run test:sites` 通过，产物包含 `dist/client/index.html`、`dist/server/index.js`、`dist/.openai/hosting.json`。

本轮浏览器版本完成代码、模型几何与构建检查，并提供本地预览；没有进行浏览器交互和不同屏幕的视觉实测。Unity 的实际运行截图与验证记录位于 Earth2 的 `docs/visual-review/expansion-*`。两版地图坐标、模型和存档格式各自独立，不能互相导入存档。
