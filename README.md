# FRONTIER / 前线指令

基于「科幻 RTS 战场场景」参考图制作的单人 3D RTS 原型。Three.js 实时渲染；2026-09-05 参考本地 Earth2 Unity 版本补充了建筑、陆海空作战、资源控制、科技和主动技能。原有地形及地面单位来自 Blender，新建筑和飞机复用 Earth2 GLB。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173 。`npm run build` 生成构建产物。

## 操作

- 左键选中部队，拖动框选，Shift 追加选择。
- 右键地面移动；右键敌军或敌方指挥中心攻击；右键晶矿采集。
- 中键拖动旋转，滚轮缩放，WASD 平移，H 返回基地。
- 1 全选战斗部队；2 命令采矿车自动往返；空格暂停；Esc 取消指令。
- 「建设」放置指挥中心、兵营、工厂、机场和船坞；绿影可建，红影不可建，R 旋转，右键取消。船坞必须在西北湖岸。
- 「生产」训练坦克、步兵、采矿车、飞机和巡逻艇，每座设施独立排队；Y 设置该设施集结点，点击队列任务取消并退款。
- 派驻地面部队控制矿区，每个矿区每 3 秒 +18 晶矿、+4 合金；双方人数相同则中立。采矿车保留额外运输收入。
- F 攻击推进，P 两点巡逻，G 护卫友军，X 停止，R 驻守；Shift 追加命令。Ctrl/⌘ + 数字保存编队，数字调用（未设编队时 1、2 保留原快捷操作）。
- Z 扫描迷雾；C 武器超载；V 战术俯视。「科技」研究弹道学、装甲及后勤网络。人口与供电由存活设施决定，低供电使生产速度减半。
- 顶部保存/载入按钮使用本浏览器 localStorage，Ctrl/⌘ S、Ctrl/⌘ L 为快捷键；载入后保持暂停。
- 摧毁敌方指挥中心获胜，己方指挥中心被摧毁则失败，结束后可重新部署。

## Blender 资产

`art/frontier-rts.blend` 是可继续编辑的完整模型源文件。`public/models/` 包含 environment、tank、enemy、infantry、harvester 五个 GLB。制作脚本为 `scripts/create-models.py`。

```sh
blender --background --python scripts/create-models.py
```

Blender 按真实几何创建模型，包含材质、倒角、履带、轮组、炮塔、机库、反应堆、树木、矿石和地形。网页端合并相同材质的静态网格，减少绘制调用。

原有 2D 单位卡片使用此前通过内置 ImageGen 生成的模板衍生图片；战术地图实时绘制可见单位、建筑和迷雾。新增模型、图标、音效的来源和与 Unity 的差异见 `docs/earth2-parity.md`。

## 验证

```sh
npm test
npm run build
npm run test:sites
```

当前范围：单人遭遇战、地面/水面 A* 寻路、建筑自由放置、采矿及区域经济、陆海空单位、科技、技能和本地存档。尚无多人联网、确定性回放或骨骼行走动画；没有完整移植 Unity 物理、动画、场景编辑或渲染管线。

原有上层战国游戏代码保持独立；本原型现位于 `Earth-flash` 根目录运行。
